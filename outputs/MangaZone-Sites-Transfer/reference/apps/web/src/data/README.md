# Datos de desarrollo de la Home

Los archivos de esta carpeta contienen fixtures/mock data deterministas para construir y validar la interfaz actual. No son una base de datos ni una autoridad de negocio y serán reemplazados por respuestas tipadas de la API cuando el backend esté disponible.

No deben añadirse aquí secretos, credenciales, decisiones de autorización ni estado persistente de usuarios.
